# 보육비서 사용 가이드

개정: 2026-10-03 · 버전 3.5.2

앱: https://daycare-helper.awslike6.workers.dev/

## 처음 한 번: 휴대폰 등록

관리자가 보낸 자기 담당반 등록 링크를 본인 휴대폰에서 엽니다. 처음에는 원하는 4자리 PIN을 두 번, 추가 기기는 기존 PIN을 입력합니다. PIN을 채팅으로 보내지 마세요.

PIN 등록을 마치기 전에는 주소의 #register 정보를 유지합니다. 열어둔 주소를 복사하거나 새로고침해도 유효한 등록 문맥을 유지하며, 성공 후에는 주소에서 제거합니다. 만료·사용된 링크는 새로 받으세요. 등록된 기기는 일반 앱 주소에서 기존 PIN으로 들어갑니다. 연구반도 같은 원리입니다.

기기 등록은 최대 30일이며 한 시간 동안 쓰지 않으면 PIN으로 잠깁니다. 등록 만료 시 새 링크를 받습니다. 설정에서 현재 PIN·새 PIN·새 PIN 확인으로 변경할 수 있습니다. 분실한 PIN의 자동 복구 기능은 아직 없습니다.

## 매일: 메모에서 일지까지

1. 자기 반 원아와 실제 관찰일을 선택합니다. 학급 전체 보육일지는 반 전체를 선택합니다.
2. 실제 행동을 짧게 적거나 음성으로 남깁니다. 음성 인식은 브라우저와 마이크 권한에 따라 지원됩니다.
3. 필요한 사진을 최대 6장 첨부합니다. 얼굴·이름표를 가리고 외부 AI 전송 동의를 확인합니다.
4. 필요한 서식만 선택해 생성합니다.
5. 놀이 행동·배움·성찰·지원·알림장·평가·상담 문장과 원아별 요약을 다듬습니다. 실행한 지원과 앞으로 할 계획을 구분합니다.
6. 사실 확인 체크 후 노션에 저장합니다. 오류가 나오면 내용은 보관하고 연결을 확인한 뒤 재시도합니다.
7. 한그루 복사·HWP 표 복사·알림장 복사로 해당 프로그램에 붙여넣습니다. 자동 발송되지 않으므로 교사가 최종 확인합니다.

**생성 완료와 노션 저장 완료는 별도입니다.** 검수 확인을 체크하고 [오늘의 기록 노션에 저장]을 누른 뒤, 화면에 남는 ‘노션 저장 완료’를 확인하세요. 같은 날짜 기록이 있으면 열린 창에서 저장 방식을 선택해야 저장됩니다. 문장을 다시 수정하면 재검수·저장이 필요합니다.

저장 버튼이 잠시 흐려져 있으면 진행 상태를 확인하세요. 중복 선택 창에서 취소하면 다시 누를 수 있습니다. 쓰기 응답이 없으면 최대 2분 뒤 오류가 표시되고 버튼이 복구됩니다. 도중에 잠금 화면으로 돌아갔다면 PIN으로 들어가 [이어서 작성하기]를 누르세요. 쓰기 도중 잠겼거나 응답을 못 받은 경우 보관함을 먼저 확인하여 중복 저장을 피합니다.

로그인 화면 아래 설명에 v3.5.2가 표시되는지 확인하세요. 연결이 실패하면 [연결 다시 확인]을 누릅니다. 버전이 다르면 작성 내용을 복사해 따로 보관한 뒤 페이지를 새로 열어 주세요. 브라우저 데이터 삭제는 임시보관 내용을 지울 수 있습니다.

사진·서식이 많으면 생성 시간이 늘어날 수 있습니다. 경과 시간과 오류를 확인하고, 일시 장애라면 잠시 후 재시도하세요. 선불 잔액 안내가 나오는 경우에만 프로젝트 결제 설정을 확인합니다. 저장 응답을 확인하지 못했다면 먼저 보관함을 조회하여 중복 저장을 피하세요.

## 월간 관찰·발달평가·상담 준비

원아를 선택하고 **과거 관찰 기록 선택**에서 기간을 조회합니다. 관찰 요약과 원시 메모를 읽고 사용할 기록을 체크하여 생성합니다. 월간 관찰일은 오늘 또는 선택한 실제 기록의 날짜를 넣습니다. 부족한 영역은 기록 부족 문구를 유지하고 관찰을 더 모읍니다.

학급 전체 일지는 원아별 요약을 검수하여 해당 원아 기록으로 분할 저장해야 다음 평가에 연결됩니다. 상담 준비 초안에 실제로 하지 않은 학부모 발언·합의를 적지 않습니다.

## 수정·복원·출력

- 보관함에서 **화면에 복원하기**를 누르면 메모·날짜·원아·검수한 서식이 돌아옵니다. 이전 기록 더 보기로 오래된 기록을 불러옵니다.
- 같은 날짜·원아는 **이어서 추가 / 덮어쓰기 / 별도 저장**을 선택합니다.
- 현재 보고 있는 서식을 인쇄합니다. 실제 한그루 입력칸·HWP 붙여넣기·프린터 결과는 사용하는 기기에서 확인해 주세요.
- 임시보관 안내가 있으면 **이어서 작성하기**를 먼저 누릅니다. 브라우저 데이터 삭제나 저장 공간 부족으로 기기 초안이 없어질 수 있으므로 완성본은 노션에 저장합니다.
- 원아·날짜를 바꾸면 이전 생성 결과를 숨깁니다. 새 대상으로 다시 생성해 잘못된 저장을 막습니다.

## 문체 설정

문체 프리셋과 평소 알림장 예시문을 저장하면 자기 교사의 노션 프로필에 반영됩니다. 예시 사건은 오늘 관찰로 사용하지 않습니다. 담당반·교사 이름은 노션의 실제 정보를 따릅니다.

## 관리자 도구

- 등록 링크 갱신: node scripts/create_device_invite.mjs 사랑반 또는 소망반. 링크는 30분 동안 한 번만 쓰며 공개 문서·Git에 남기지 않습니다.
- 운영 노션 단독 검증: node scripts/verify_connections.mjs --notion-only. 연구반 가상 메모를 쓰고 읽어 일치를 확인한 뒤 즉시 보관합니다. 옵션을 빼면 실제 AI와 누적 근거 연결까지 검증하며 결과의 ai 값을 구분해야 합니다.
- 관리자 비밀값과 AI 키는 Cloudflare Secret 및 로컬 비공개 환경파일에만 둡니다.
- 보육비서 전용 Gemini 키를 설정하여 기존 공용 키 배포 경로와 분리합니다.
- PIN 분실·기기 분실 대응과 이메일 인증 확장은 후속 관리 기능으로 남아 있습니다.
