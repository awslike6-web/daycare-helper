# 보육비서 사용 가이드

개정: 2026-10-06 · 버전 3.6.4

앱: https://daycare-helper.awslike6.workers.dev/

매일은 **원아·관찰일 선택 → 실제 행동 메모 → 메모 저장 완료 확인**부터 시작합니다. 월·분기 서류는 아래의 **월간 관찰·발달평가·상담 준비** 절차를 사용합니다. 원시 메모 자동 저장, AI 생성, 검수 완성본 저장은 별도입니다.

## 처음 한 번: 휴대폰 등록

관리자가 보낸 자기 담당반 등록 링크를 본인 휴대폰에서 엽니다. 처음에는 원하는 4자리 PIN을 두 번, 추가 기기는 기존 PIN을 입력합니다. PIN을 채팅으로 보내지 마세요.

휴대폰과 PC 등 여러 기기를 함께 사용할 수 있습니다. 기기·브라우저마다 별도의 일회용 링크로 한 번 등록하고 같은 교사의 PIN을 사용합니다. PC의 Chrome과 Edge도 각각 등록합니다. 추가 등록은 기존 기기를 해제하지 않으며, 30일 자동 연장과 [이 기기 등록 해제]는 해당 브라우저에만 적용됩니다. 원시 메모는 노션 자동 저장 후 같은 교사·원아·날짜로 다른 기기에서 조회합니다. 미전송 기기 초안·사진·검수 중 완성 서식은 기기 간 자동 동기화되지 않습니다.

PIN 등록을 마치기 전에는 주소의 #register 정보를 유지합니다. 열어둔 주소를 복사하거나 새로고침해도 유효한 등록 문맥을 유지하며, 성공 후에는 주소에서 제거합니다. 만료·사용된 링크는 새로 받으세요. 등록된 기기는 일반 앱 주소에서 기존 PIN으로 들어갑니다. 연구반도 같은 원리입니다.

등록한 휴대폰에서 PIN으로 로그인할 때마다 기기 등록이 그날부터 30일 자동 연장됩니다. 30일 안에 PIN 로그인을 계속하면 새 링크를 받을 필요가 없습니다. 단순히 화면을 보거나 기존 로그인 상태를 확인하는 것만으로는 연장되지 않습니다. 30일 동안 PIN 로그인하지 않았거나 기기 등록을 해제했다면 새 링크를 받아 기존 PIN으로 등록하세요.

한 시간 동안 쓰지 않으면 PIN으로 잠깁니다. ‘로그인 상태를 최대 30일 유지하기’는 로그인 인증정보의 보관 기간을 선택하며, 체크를 꺼도 기기는 PIN 로그인마다 30일 연장됩니다. 설정에서 현재 PIN·새 PIN·새 PIN 확인으로 변경할 수 있습니다. 분실한 PIN의 자동 복구 기능은 아직 없습니다.

홈 화면에 아이콘을 추가하려면 브라우저의 **홈 화면에 추가 / 앱 설치** 메뉴를 이용합니다. 기기·브라우저에 따라 지원 여부와 메뉴 위치가 다릅니다. 아이콘에서 다시 등록을 요구하면 그 환경의 등록 링크를 받습니다. 로그인 후 앱 안의 **음성 메모**와 **기록 보관함**을 사용하세요.

## PC·다른 휴대폰: 등록 링크 직접 발급

1. 이미 등록한 휴대폰에서 로그인하고 오른쪽 위 ⚙️ 설정을 엽니다.
2. [새 기기 등록 링크]를 누르고 현재 PIN 4자리를 입력한 뒤 [링크 발급]을 누릅니다.
3. [링크 복사]로 주소를 복사하여 새 기기에 전달합니다. 지원하는 휴대폰에서는 [공유]도 사용할 수 있습니다. 자동 복사가 막히면 링크 칸을 길게 눌러 직접 복사합니다.
4. 새 기기의 사용할 브라우저에서 링크를 열고 같은 기존 PIN으로 등록합니다. PC의 Chrome과 Edge는 각각 별도의 링크로 등록합니다.

링크는 30분 동안 한 번만 사용할 수 있습니다. 같은 기기에서 다시 발급하면 이전 링크는 무효화됩니다. 발급한 기기의 등록을 해제하거나 PIN을 바꾸면 이전 미사용 링크도 다시 발급해야 합니다. 등록된 기기가 하나도 없으면 관리자가 첫 링크를 발급해야 합니다. 설정을 닫으면 화면의 PIN·링크가 지워지므로 먼저 복사하세요.

## 매일: 메모에서 일지까지

### 메모는 작성하면 자동 저장됩니다

- 원아와 실제 관찰일을 먼저 선택합니다. 입력을 5초 멈추면 노션 저장을 시도하고, 계속 입력하면 최대 30초마다 전송을 시도합니다. AI 생성이나 검수 체크는 필요 없습니다.
- 메모 아래의 **원시 메모 노션 저장 완료**와 시간을 확인합니다. 바로 저장하려면 **지금 메모 저장**을 누릅니다. 화면 숨김·다른 앱 전환 때도 전송을 시도하지만 종료 순간 저장은 보장하지 않습니다.
- PC에서도 자기 교사로 로그인하여 **같은 원아·날짜**를 선택합니다. 처음 열기·대상 변경·화면 복귀·활성 화면 30초마다 조회합니다. **노션 메모 다시 조회**로 즉시 확인할 수 있습니다.
- 두 기기에서 동시에 수정하면 현재 입력과 노션 메모를 모두 보여주고 자동 덮어쓰기를 멈춥니다. **두 메모 합쳐서 편집** 후 중복 문장을 정리하거나 **노션 메모 사용**을 선택합니다.
- 인터넷이 끊기면 대상별 암호화 기기 초안으로 남깁니다. 재진입·연결 복구 후 노션의 버전을 확인하여 전송합니다. 브라우저 데이터 삭제·저장 공간 부족·암호화 전 강제 종료 시 미전송 내용은 없어질 수 있습니다.
- **비우기**는 이 기기의 입력창과 사진만 비웁니다. 노션 메모를 삭제하지 않습니다. 저장본은 다시 조회할 수 있습니다. 사진은 자동 노션 저장 대상에 포함하지 않습니다.
- **사진만 첨부한 경우** 생성 요청은 가능하지만 텍스트 원시 메모가 없어 [지금 메모 저장]으로 노션에 사진을 보관할 수 없습니다. 원본은 갤러리에 유지하세요. 반복되는 생성 오류는 관리자 연결 점검이 필요하며 브라우저 재등록으로 복구하지 않습니다.
- 노션에는 날짜·원아·교사별 **[원시메모:…]** 행 하나를 갱신합니다. 이 행은 검수 완료 일지와 구분되며 보관함과 근거 선택에서 원문을 확인할 수 있습니다. 반 전체 메모는 자동으로 모든 원아의 개별 기록으로 분할되지 않습니다.
- 저장 응답이 불명확하면 먼저 노션 반영 여부를 재조회합니다. 최초 생성이 확인되지 않는 상태에서는 중복 행을 만들지 않고 대기합니다. 계속되면 관리자에게 연결 확인을 요청합니다.

### 원아별 정확한 연결

반 전체를 선택하고 메모에 아이 이름을 적으면 **이름으로 찾은 원아별 기록**에 문장이 자동으로 나타납니다. AI 생성 버튼을 누를 필요가 없습니다.

1. 카드의 원아와 원문을 확인합니다. 성을 뺀 이름은 **이름 약칭**, 여러 아이가 나온 문장은 **행동 역할 확인**으로 표시됩니다. 동명이인은 연령·구분 번호를 보고 직접 원아를 선택합니다.
2. 원문 근거의 범위를 줄이거나 바꿀 때는 위 메모의 실제 문장을 그대로 가져옵니다. 관찰 요약은 선택 사항이며 실제 행동만 적습니다.
3. **이 원아의 행동과 원문을 확인했습니다**를 카드마다 체크하고 **확인한 건 노션에 저장**을 누릅니다. 성공한 카드에는 저장 완료 표시가 남습니다. 일부 실패하면 성공 기록은 유지하고 남은 확인 항목만 다시 저장합니다.
4. **이름 없는 문장 · 반 공통 활동**을 펼쳐 빠진 문장도 확인합니다. 앞 문장의 아이에게 자동으로 붙이지 않습니다. 개별 행동이면 **원아를 직접 선택해 연결**로 후보를 추가하고 반 공통 활동이면 원본에 남겨둡니다.

메모 변경·카드 수정·재진입 복원 뒤에는 확인을 다시 받습니다. 수정한 요약과 원아 선택은 암호화 초안에 보관합니다. 이름 탐색은 줄바꿈/마침표 등 문장 경계와 등록된 이름/조사를 이용합니다. 자유로운 애칭·오탈자·일반 단어와 겹치는 이름은 누락되거나 후보가 부정확할 수 있으므로 실제 행동 주체를 확인합니다. 한 번에 100건까지 제안하며 넘으면 메모를 나누어 작업하세요.

직접 문장을 골라 연결하려면 기존 메뉴도 사용할 수 있습니다.

예를 들어 `민수 블록 쌓음, 민서 공 굴림`은 새 이름이 시작되는 쉼표에서 나누어 제안합니다. `민수가 공을 잡고, 민서에게 건넴`은 공동 문장으로 유지합니다. 문장부호 없는 긴 음성 메모는 여러 행동이 한 카드에 남을 수 있으니 아이별로 줄바꿈하거나 원문 범위를 줄여 확인하세요.

1. 반 전체 메모를 썼다면 **원시 메모를 원아별 기록에 연결**을 엽니다. AI 생성 전에도 사용할 수 있습니다.
2. **연결할 원아**를 선택합니다. 이름이 같으면 연령과 **구분 번호**를 확인합니다. 노션의 별도 원아 정보와 대조해 선택하세요.
3. 위 메모에서 그 아이의 문장만 선택하고 **선택한 원문 가져오기**를 누릅니다. 직접 복사해 **이 아이의 원문 근거**에 붙여 넣어도 됩니다. 원문과 다르게 고친 문장은 저장하지 않으므로 원문에서 그대로 가져옵니다.
4. 관찰 요약은 선택 사항입니다. 확인한 행동만 적고 **선택한 원아의 행동과 근거를 확인했습니다**를 체크한 뒤 **원아 기록에 연결 저장**을 누릅니다.
5. 연결 완료 표시를 확인합니다. 개인 기록에는 발췌문만 남고 반 전체 메모와 원문 출처는 별도로 보존합니다. 다른 아이에게도 연결하려면 원아·근거를 바꾸고 다시 확인합니다.

생성된 **감지된 원아별 놀이 요약**도 원아·원문 근거·요약을 확인한 카드만 체크합니다. 전체 **실제 관찰 사실과 원아별 요약을 확인했습니다**도 체크하고 개별 저장 버튼을 누릅니다. 원아 후보는 저장 전에 확인해야 하며 동명이인은 자동으로 첫 아이를 고르지 않습니다. 사진만 있고 원문 근거가 없으면 실제 관찰 문장을 메모에 추가하고 다시 생성합니다.

원문이 다른 기기에서 바뀌었거나 아직 노션 저장본과 다르면 연결을 멈춥니다. 저장 완료/충돌 안내를 확인하고 최신 원문을 사용하세요. 같은 원문·원아·발췌를 다시 저장하면 같은 기록을 사용합니다. 기존 연결의 관찰 요약을 수정해 저장하면 같은 기록에 반영합니다. 원문을 나중에 수정해도 이미 연결한 발췌가 자동으로 바뀌지는 않습니다.

### 서식 생성·검수·출력

1. 자기 반 원아와 실제 관찰일을 선택합니다. 학급 전체 보육일지는 반 전체를 선택합니다.
2. 실제 행동을 짧게 적거나 음성으로 남깁니다. 음성 인식은 브라우저와 마이크 권한에 따라 지원됩니다.
3. 필요한 사진을 최대 6장 첨부합니다. 얼굴·이름표를 가리고 외부 AI 전송 동의를 확인합니다.
4. 필요한 서식만 선택해 생성합니다.
5. 놀이 행동·배움·성찰·지원·알림장·평가·상담 문장과 원아별 요약을 다듬습니다. 실행한 지원과 앞으로 할 계획을 구분합니다.
6. 사실 확인 체크 후 노션에 저장합니다. 오류가 나오면 내용은 보관하고 연결을 확인한 뒤 재시도합니다.
7. 한그루 복사·HWP 표 복사·알림장 복사로 해당 프로그램에 붙여넣습니다. 자동 발송되지 않으므로 교사가 최종 확인합니다.

**원시 메모 자동 저장·AI 생성 완료·검수 완성본 저장은 별도입니다.** 검수 확인을 체크하고 **검수한 작성 내용 노션에 저장**을 누른 뒤, 화면에 남는 ‘노션 저장 완료’를 확인하세요. 같은 날짜 완성본이 있으면 열린 창에서 저장 방식을 선택해야 저장됩니다. 취소하면 새 내용은 저장되지 않습니다. 문장을 다시 수정하면 재검수·저장이 필요합니다.

저장 버튼이 잠시 흐려져 있으면 진행 상태를 확인하세요. 중복 선택 창에서 취소하면 다시 누를 수 있습니다. 쓰기 응답이 없으면 최대 2분 뒤 오류가 표시되고 버튼이 복구됩니다. 도중에 잠금 화면으로 돌아갔다면 PIN으로 들어가 [이어서 작성하기]를 누르세요. 쓰기 도중 잠겼거나 응답을 못 받은 경우 보관함을 먼저 확인하여 중복 저장을 피합니다.

이번 가이드의 월·분기 개선은 운영 v3.6.3에 적용됐습니다. 로그인 화면의 v3.6.3 표시를 확인하세요. 연결이 실패하면 [연결 다시 확인]을 누릅니다. 이전 버전이면 작성 내용을 복사해 따로 보관한 뒤 페이지를 새로 열어 주세요. 브라우저 데이터 삭제는 임시보관 내용을 지울 수 있습니다.

PIN이 맞지 않으면 ‘PIN이 맞지 않습니다’가 표시됩니다. 새 등록 링크도 기존 계정의 PIN은 바꾸지 않습니다. 5회 실패 시 15분 뒤 다시 시도합니다. 만료·사용된 링크는 등록된 기기에서 다시 발급하고 등록 기기가 없을 때 관리자에게 요청합니다. PIN 숫자를 채팅으로 보내지 마세요.

사진·서식이 많으면 생성 시간이 늘어날 수 있습니다. 경과 시간과 오류를 확인하고, 일시 장애라면 잠시 후 재시도하세요. 선불 잔액 안내가 나오는 경우에만 프로젝트 결제 설정을 확인합니다. 저장 응답을 확인하지 못했다면 먼저 보관함을 조회하여 중복 저장을 피하세요.

## 월간 관찰·발달평가·상담 준비

1. 원아를 선택합니다. 상단 날짜는 **서류 작성일**이며 과거 사건의 **관찰일**은 선택한 근거에 남습니다. 오늘 작성하는 지난달 평가라면 상단 날짜를 지난달로 바꿀 필요가 없습니다.
2. **과거 관찰 기록 선택**을 열고 **이번 달 / 지난달 / 이번 분기 / 지난 분기**로 기간을 채웁니다. 버튼은 상단 작성일을 기준으로 계산합니다. 분기는 1~3·4~6·7~9·10~12월이며 진행 중인 기간은 작성일까지입니다. 학기 등 다른 기간은 시작·종료일을 직접 지정합니다.
3. **기록 조회** 후 원문을 읽고 사용할 기록을 체크합니다. 기간·원아·작성일을 바꾸면 다시 조회·선택합니다. 조회는 최대 500건, 생성당 선택은 최대 60건이므로 많으면 기간을 좁힙니다. 기간 안의 기록이 자동으로 모두 선택되지는 않습니다.
4. 오늘 메모·사진 없이 작성하려면 **한그루 관찰일지 (월2회) / 한그루 발달평가 (월·분기·학기) / 학부모 상담일지** 중 필요한 것만 켜고 다른 서식은 끕니다. 서식은 최소 하나를 유지하므로 필요한 기간 서식을 먼저 켭니다.
5. 생성 후 참조 기간·원문·실제 관찰일을 대조해 검수하고 **검수한 작성 내용 노션에 저장**을 누릅니다. 발달평가 화면과 복사본의 시작·종료일도 확인합니다.

예를 들어 2026년 10월 4일에 **지난 분기**를 누르면 7월 1일~9월 30일이 참조 기간입니다. 발달평가는 그 기간을 종합하고, 월간 관찰일지는 참조 종료 월인 9월을 기본 대상으로 작성합니다. 7월·8월의 월간 서류도 필요하면 해당 월의 기간과 기록을 따로 선택합니다.

월간의 놀이·일상생활 관찰에는 대상 월에 실제 기록한 날짜만 사용합니다. 해당 유형이 없으면 날짜를 임의로 채우지 말고 **관찰 기록 부족**을 유지한 채 관찰을 더 모읍니다. 대상 월·관찰일을 바꿔 **선택한 관찰일로 다시 작성**을 누르면 선택한 서식이 다시 생성되므로 수정 중인 문장을 먼저 보관하고 재검수합니다.

**기록 없음은 행동하지 않았다는 뜻이 아닙니다.** 비교할 기록이 부족하면 성장·지도 효과를 단정하지 않습니다. 수행한 지원과 앞으로의 계획을 구분하고 상담 준비 초안에 실제로 하지 않은 학부모 발언·합의를 적지 않습니다.

오늘 입력 없이 과거 자료만으로 만든 서류는 **기간 종합 서류**로 별도 보관합니다. 선택 근거·기간과 검수 문장을 복원할 수 있지만 다음 생성의 새 관찰 사실로 선택할 수 없습니다. 다음 평가에는 원래 관찰 기록을 선택하세요. 기기 등록이 30일 뒤 만료돼도 노션 관찰 기록이 지워지는 것은 아닙니다.

학급 전체 메모의 개인 행동은 원아별 원문 근거와 요약을 확인해 연결 저장해야 개인 평가 근거에 나타납니다. **원아별 연결 확인 필요**로 표시된 이전 자동 분할·여러 원아 연결 기록은 선택할 수 없습니다. 원문을 확인해 개인 근거를 다시 연결하며 기존 기록을 추측하여 소급 수정하지 않습니다.

## 수정·복원·출력

- 보관함에서 **화면에 복원하기**를 누르면 메모·날짜·원아·저장한 검수 서식이 돌아옵니다. 선택 근거·기간도 복원하며 **이전 기록 더 보기**로 오래된 기록을 불러옵니다. 전체 서식이 없는 이전 기록은 원시 메모만 복원됩니다.
- 같은 날짜·원아의 완성본은 **이어서 추가**로 내용을 합치거나 **덮어쓰기**로 최신 저장본을 바꾸거나 **별도 저장**으로 새 기록을 만듭니다. 기간 종합본은 같은 기간끼리만 추가·덮어쓰기하며 원래 관찰이나 다른 기간과 합치지 않습니다.
- 원래 서식으로 출력하려면 복원 후 원하는 서식 탭에서 **한그루 복사 / 한글(HWP) 표 복사 / A4 인쇄/PDF**를 사용합니다. 보관함 상세의 **텍스트 복사**는 저장 데이터이고 **인쇄**는 상세 내용이므로 현재 서식 출력과 구분합니다.
- 복사 완료 표시를 확인하고 실제 한그루 입력칸·HWP 붙여넣기·인쇄 미리보기에서 날짜·문장·표 모양을 확인합니다. 한그루·키즈노트에는 교사가 직접 붙여넣으며 자동 발송하지 않습니다.
- 임시보관 안내가 있으면 **이어서 작성하기**를 먼저 누릅니다. 브라우저 데이터 삭제나 저장 공간 부족으로 기기 초안이 없어질 수 있으므로 완성본은 노션에 저장합니다.
- 원아·날짜를 바꾸면 이전 생성 결과를 숨깁니다. 새 대상으로 다시 생성해 잘못된 저장을 막습니다.

## 문체 설정

문체 프리셋과 평소 알림장 예시문을 저장하면 자기 교사의 노션 프로필에 반영됩니다. 예시 사건은 오늘 관찰로 사용하지 않습니다. 담당반·교사 이름은 노션의 실제 정보를 따릅니다.

## 관리자에게 확인할 때

등록된 기기가 없거나 PIN을 잊었다면 관리자에게 문의합니다. PIN과 등록 링크는 공개 문서·채팅에 남기지 않습니다. 오류를 알려줄 때는 원아의 실제 메모 대신 실패한 단계·시각·오류 문구를 전달하세요. 관리자의 등록·연결 검증 명령은 [공통 부품·운영 도구 지도](CORE_CATALOG.md)에 따로 정리했습니다.
