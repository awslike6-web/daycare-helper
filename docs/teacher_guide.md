## 🚀 4. 목적별 3대 실무 모드 활용법

### ① 📸 놀이 알림장 (키즈노트 맞춤형)
- **추천 대상**: 매일 학부모님께 발송하는 감동 알림장
- **기능**: 아이 활동 사진(최대 6장) 첨부 + 키워드 입력
- **특징**: 학부모님이 읽고 감동하는 생생한 표정과 놀이 몰입 과정 묘사, 가정 연계 대화 팁까지 자동 수록!

### ② 📄 놀이 보육일지 (A4 정규 공문서)
- **추천 대상**: 평가제 및 원장님 결재용 정규 일지
- **기능**: 실내/바깥놀이, 일상생활, 평가 및 다음 놀이 지원 계획 완벽 수록
- **특징**: **[📋 한글(HWP) 표 복사]** 버튼을 누른 뒤, 한글 문서에서 `Ctrl + V`만 누르면 표 선과 여백 그대로 완벽하게 붙여넣기됩니다!

### ③ 🧸 평가제 월간 연속 관찰일지 (월 2회)
- **추천 대상**: 한 달에 2회 작성하는 정규 관찰기록부
- **기능**:
  - **[🎲 평일 2회 자동 분산]** 버튼 클릭 ➔ 이번 달 평일 중 상순 1회, 하순 1회가 임의의 날짜로 겹치지 않게 자동 배정!
  - 1차 관찰 시점의 행동과 놀이 ➔ 2차 관찰 시점의 지도 후 발전 변화가 스토리라인으로 매끄럽게 연결됩니다.

## 💌 6. 선생님 맞춤 피드백 요청 창구 (언제든 말씀해 주세요!)

선생님들의 손에 착 감기는 '내 맞춤 비서'가 되도록 계속해서 업그레이드해 드립니다. 아래 사항이 필요하시면 언제든 편하게 말씀해 주세요!

1. **📋 우리 어린이집 결재 양식과 달라요!**  
   - 원에서 실제로 쓰시는 한글(HWP) 양식 파일이나 빈 서식 사진을 보내주시면, 칸 구조와 항목명을 100% 똑같이 맞춰서 출력되도록 커스텀해 드립니다.
2. **💬 평소 제 말투랑 조금 달라요!**  
   - "저는 '~했답니다'보다는 '~했어요!'를 자주 써요", "이런 이모티콘을 좋아해요" 등 평소 마음에 드셨던 본인 작성 알림장 1~2편을 카톡으로 보내주시면 선생님 고유의 말투와 감성을 그대로 복제해 드립니다.
3. **👶 아이의 새로운 버릇이나 특이사항이 생겼어요!**  
   - 상단 원아 목록에서 아이를 누른 뒤 **[✏️ 성향 수정]**에 한 줄(예: *"요즘 공룡 이름 맞추기에 푹 빠짐"*, *"오이 편식이 생김"*)만 적어두시면, 이후 생성되는 모든 글에 AI가 아이의 개성을 100% 반영합니다.
4. **기타 아이디어 & 불편한 점**:  
   - "이 버튼 위치가 불편해요", "이 기능도 생기면 좋겠어요" 등 사소한 의견이라도 말씀해주시면 즉시 반영해 드립니다!
