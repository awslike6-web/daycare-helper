## 🎙️ 3. 말로 툭툭 던지는 [음성 메모] & 든든한 [안심 저장/비우기]

교실에서 아이들을 돌보시느라 바쁘신데 긴 문장을 타이핑하실 필요가 전혀 없습니다!

1. **말만 툭툭 던지세요**:  
   - **[🎙️ 음성 메모]** 버튼을 누르고 *"블록 쌓다가 무너졌는데 울지 않고 선생님 부름. 친구한테 기차 양보함"*처럼 키워드만 말하면 예쁜 문장으로 착착 적힙니다.
2. **실시간 자동저장 (Autosave)**:  
   - 메모를 적는 도중 화면이 꺼지거나 실수로 새로고침되어도 적어둔 내용이 날아가지 않고 안전하게 보존됩니다.
3. **실수 방지 2-Tap 안심 비우기 (3초의 마법)**:  
   - 우측 상단 **[🗑️ 비우기]** 버튼을 1번 누르면 주황색으로 바뀌며 *"3초 안에 한 번 더 누르면 비워져요"*라는 안내가 뜹니다.
   - 3초 안에 한 번 더 눌러야만 비워지며, 3초가 지나면 원래대로 돌아오므로 실수로 소중한 메모를 날릴 걱정이 100% 없습니다!
4. **생성 즉시 중단 (⏹️)**:  
   - AI가 글을 쓰는 도중에 *"아, 이 내용 빼먹었네!"* 하고 멈추고 싶다면 언제든 **[⏹️ 생성 중단]** 버튼을 누르면 1초 만에 멈추고 메모를 수정할 수 있습니다.

## 📑 4. [v3.3] 내 맘대로 콕콕! [6대 서식 선택 툴바] (초고속 4초 완성)

매번 한꺼번에 모든 일지를 뽑을 필요 없이, 메모창 아래의 **토글 칩**에서 오늘 뽑고 싶은 서식만 켜두면 한 번에 싹 작성됩니다!

| 서식 칩 명칭 | 기본 설정 | 추천 활용 시점 및 특징 |
| :--- | :---: | :--- |
| **📄 놀이 보육일지** | **ON (기본)** | **평가제 및 원장님 결재용 정규 A4 공문서** ([한글 HWP 표 복사] 지원) |
| **📸 키즈노트 알림장** | **ON (기본)** | **매일 학부모님께 발송하는 다정한 놀이 이야기** (250~400자 생생 서술) |
| **🧸 평가제 관찰일지** | OFF | **한 달에 2회 작성하는 영유아 발달 관찰기록부** (1차 ➔ 2차 발전 변화 연계) |
| **📋 일일 보육일지** | OFF | **반 전체 놀이 평가 및 내일 놀이 연계/환경 지원 계획** |
| **🤝 학부모 상담일지** | OFF | **1학기/2학기 학부모 개별 면담록** (기본생활/사회성/발달 특성 분석) |
| **🎨 놀이 지원안** | OFF | **유아 흥미 확장 아이디어 및 추천 준비 교구 목록** |

> ⭐ **설정 상태 평생 기억 (`localStorage`)**  
> 한 번 골라둔 서식 조합은 브라우저를 닫거나 앱을 껐다 켜도 **내 설정 그대로 자동 유지**됩니다. 매번 다시 누르실 필요가 없습니다.  
> 
> ⚡ **생성 속도 3배 가속 (15초 ➔ 4초)**  
> 평소에는 자주 쓰는 `[보육일지 + 알림장]` 2개만 켜두시면, AI가 불필요한 서식을 생성하지 않아 **기존 15초 대기 시간이 단 4~5초로 대폭 단축**됩니다!

## 🌱 5. 아이 이름만 적으면 끝! [원아 자동 감지 & 분할 저장]

매번 아이 목록에서 아이를 한 명씩 고를 필요가 없습니다!

1. 상단 원아 선택은 기본으로 **`[🌱 우리 반 (학급 전체)]`**로 맞춰져 있습니다.
2. 메모창에 아이들 이야기(예: *"지안이가 블록으로 레일을 길게 깔고, 하준이가 기차를 굴리며 칙칙폭폭 소리 냄"*)를 편하게 적으세요.
3. 생성 완료 후 보육일지 화면을 보시면 AI가 메모 속 아이 이름을 스스로 인식하여:
   - **`[🧩 선택한 원아 (2명) 개별 관찰일지 DB에 반영]`** 버튼이 나타납니다.
4. 버튼을 한 번만 클릭하시면, 지안이와 하준이의 개인 노션 관찰일지 행으로 **핵심 관찰 내용이 각각 쏙쏙 분할 저장**됩니다!

## 💌 9. 선생님 맞춤 피드백 요청 창구 (언제든 말씀해 주세요!)

선생님들의 손에 착 감기는 '나만의 맞춤 비서'가 되도록 계속해서 업그레이드해 드립니다. 아래 사항이 필요하시면 언제든 편하게 말씀해 주세요!

1. **📋 우리 어린이집 결재 양식과 달라요!**  
   - 원에서 실제로 쓰시는 한글(HWP) 양식 파일이나 빈 서식 사진을 보내주시면, 칸 구조와 표 모양을 100% 똑같이 맞춰서 출력되도록 커스텀해 드립니다.
2. **💬 평소 제 말투랑 조금 달라요!**  
   - "저는 '~했답니다'보다는 '~했어요!'를 자주 써요", "이런 이모티콘을 좋아해요" 등 평소 마음에 드셨던 본인 작성 알림장 1~2편을 보내주시면 선생님 고유의 말투와 감성을 그대로 복제해 드립니다.
3. **👶 아이의 새로운 버릇이나 특이사항이 생겼어요!**  
   - 상단 원아 목록에서 아이를 누른 뒤 **[✏️ 수정]**에 한 줄(예: *"요즘 공룡 이름 맞추기에 푹 빠짐"*, *"오이 편식이 생김"*)만 적어두시면, 이후 생성되는 모든 글에 AI가 아이의 개성을 100% 반영합니다.
4. **기타 아이디어 & 불편한 점**:  
   - "이 버튼 위치가 불편해요", "이 기능도 생기면 좋겠어요" 등 사소한 의견이라도 말씀해주시면 즉시 반영해 드립니다!
