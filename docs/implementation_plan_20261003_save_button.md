# 보육비서 저장 버튼 멈춤 복구 계획

## 확인한 범위

사용자는 저장 버튼을 누를 수 없었다고 전달했다. 첨부는 로그인 화면이므로 어떤 저장 버튼인지 추가 확인 중이다. 사진의 교사 선택 구조는 이전 화면과 같지만 촬영 시점과 캐시 여부는 아직 확인되지 않았다.

코드에는 중복 저장 선택을 기다리던 중 인증 화면이 잠기면 선택 Promise를 종료하지 않아 저장 상태와 버튼 비활성화가 남는 경로가 있다. 로그인·노션 저장 요청에도 브라우저 제한 시간이 없어 통신이 멈추면 대기가 지속될 수 있다.

## 작업 순서

1. 가상 자료로 중복 선택 → 잠금 → 다시 저장 시 멈춤을 재현하고 회귀 검사한다.
2. 잠금 시 중복 선택과 진행 요청을 취소하고 반드시 저장 상태를 해제한다. 교사 전환 뒤 이전 응답이 새 학급 화면·초안에 반영되지 않도록 검사한다.
3. 공통 JSON 요청에 제한 시간과 취소를 적용한다. 저장 결과가 불명확하면 보관함을 먼저 확인하도록 안내하고 자동 재전송하지 않는다.
4. 로그인 로딩·버전·재시도와 저장 대기 상태를 화면에 표시한다. 저장 전 검수 확인과 중복 선택 규칙은 유지한다.
5. 가상 종단 저장·조회, 잠금 취소, 통신 실패, 모바일·PC와 문법·AI 검증을 수행한다. 실제 노션은 연구반 가상 기록으로 쓰기·읽기 후 보관한다.
6. 명세·부품 지도·사용법·보고서를 갱신하고 운영 배포, 한국어 커밋·푸시 및 전사 노션 장애 분석 기록을 수행한다.

## 완료 판단

재현한 저장 멈춤은 해결 여부를 보고한다. 선생님 휴대폰의 실제 실패 원인은 해당 버튼과 오류 화면을 확인하기 전까지 단정하지 않는다. 운영 Gemini 503 문제는 저장 수리와 별도로 남긴다.
