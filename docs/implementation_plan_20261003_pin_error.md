# PIN 처리 중 오류 복구 계획

## 현장 보고

연구반 본인 기기 등록 링크에서 PIN을 입력하면 ‘처리 중 문제가 발생했습니다’가 표시됩니다. 실제 사용자 로그인 완료를 확인하지 못했으므로 복구 완료로 보고하지 않습니다.

## 조사 및 수정 순서

1. 실제 Cloudflare 실행기에서 가상 계정의 틀린 PIN·유효 PIN·만료 초대·재시도를 재현합니다. 사용자 PIN을 받거나 대신 입력하지 않습니다.
2. 인증의 직렬 실행 콜백 밖에서 예외를 잡는 구조를 확인합니다. Cloudflare는 콜백이 예외를 던지면 객체를 재시작하므로 정상적인 인증 거부도 통신 오류로 바뀔 수 있습니다.
3. 콜백 내부에서 오류 응답을 완성하여 인증 저장소의 예외 유출을 막고, 실패 횟수·기존 PIN·기기·초대의 보안 조건을 보존합니다.
4. Worker HTTP 응답의 등록 쿠키·후속 세션 조회와 가상 모바일 PIN 화면을 검증합니다. 운영에서는 개인 인증정보 없이 공개 프로필·초대 상태와 배포본을 확인합니다.
5. 명세·부품 지도·사용 가이드·검증 보고서를 갱신하고, 자동 검증 후 배포·Git 푸시·노션 장애 원인/조치/재발 방지 기록을 수행합니다.

## 완료 기준

- 틀린 PIN은 안내 가능한 401, 시도 제한은 429, 잘못된 초대는 403이며 저장소 재시작으로 500이 되지 않습니다.
- 가상 계정의 올바른 PIN은 기기·세션 쿠키를 발급하고 다음 세션 조회로 연결됩니다.
- 사용자 실제 PIN·서버 키·초대 토큰은 코드·공개 문서·Git·노션에 남기지 않습니다.
- 연구반 본인 휴대폰의 최종 로그인 확인은 사용자 입력으로 남아 있으면 명시합니다.
