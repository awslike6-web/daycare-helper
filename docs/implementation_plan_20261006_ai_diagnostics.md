# 운영 AI 지속 실패 점검 계획 · 2026-10-06

- 로컬 가상 요청은 정상이고 운영 Worker의 기본·대체 모델은 503 UNAVAILABLE 및 시간 초과를 반복했다. 사용자 사진·PIN을 재전송하거나 설정을 바꾸지 않는다.
- 기존 관리자 인증·동일 출처 보호를 사용하는 POST /api/admin/ai-status를 추가한다. 모델 목록과 짧은 가상 호출만 실행하며 노션을 읽거나 쓰지 않는다.
- 운영 키와 로컬 키의 동일 여부는 단방향 해시 식별자로만 비교한다. 키·상류 오류 원문·사용자 자료는 응답과 공개 문서에 남기지 않는다.
- 권한·정보 노출·실패 분류와 기존 회귀를 검증하고 명세·카탈로그·검증 보고서를 갱신한다. 운영에서 차이를 확인한 뒤 근거가 있는 설정만 복구한다.
- 사진만 있는 작성본의 서버 사진 보관은 현재 지원하지 않는다. 실제 사용자 원본을 보존하며 이를 생성 장애 원인으로 혼동하지 않는다.
- 운영 최소 요청은 정상이나 실제 서식 요청은 계속 실패했고 운영 키와 로컬 키가 다르다. 운영 시크릿 교체는 자동 승인 검토에서 명시적 승인 부족으로 거절되어 실행하지 않았다. 승인 전에는 진단·오류 안내·문서만 완료하며 시크릿 교체를 우회하지 않는다.

## 선불제 연결 후 후속 결과

- 사용자가 선불제 연결을 완료한 뒤 운영 키를 유지하고 최소 요청 및 실제 서식 경로를 재검증한다.
- 최소 요청 3종과 운영 종단 검증 HTTP 200. 기본 모델의 서식 7종 생성·선택 근거·검수 문장 저장/조회·가상 자료 보관 처리 완료.
- 기존 키로 정상화되어 키 교체는 보류한다. 결제 연결이 직접 원인이었는지는 확정하지 않는다. 실제 사용자 사진 3장 요청의 성공 여부는 별도 확인하며 기존 당일 장애 기록에 복구 증거를 누적한다.
