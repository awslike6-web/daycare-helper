# 등록된 기기에서 새 기기 등록 링크 직접 발급 계획

## 승인한 사용 흐름

등록된 기기의 로그인한 교사가 설정에서 [새 기기 등록 링크]를 누르고 현재 PIN을 확인하면 자기 계정의 추가 기기 링크를 발급합니다. [링크 복사]로 PC·다른 브라우저에 전달하고, 새 기기는 해당 링크와 기존 PIN으로 등록합니다. 링크는 30분·일회용이며 동일 발급 기기에서 다시 발급하면 이전 미사용 링크를 무효화합니다.

## 구현과 경계

1. 기존 AuthStore의 초대·PIN·기기·세션 엔진을 재사용합니다. 새 POST /api/auth/device-invite는 같은 출처 JSON·등록 기기·유효 세션·현재 PIN을 모두 확인하고 서버의 실제 노션 교사·담당반으로 대상을 정합니다.
2. 사용자 발급 링크는 발급 기기와 PIN 버전에 연결합니다. 발급 기기 등록 해제·만료·PIN 변경 시 미사용 링크도 거부합니다. 기존 관리자 초대와 PIN 등록·30일 연장 동작은 유지합니다.
3. 설정에 PIN 확인·발급 상태·읽기 전용 링크·복사·지원 브라우저의 공유 기능을 추가합니다. PIN·링크는 영구 저장하지 않습니다. 잠금·교사 전환·설정 닫기 시 입력과 링크·대기 요청을 제거하고 늦은 응답을 반영하지 않습니다.
4. 실제 workerd와 분리된 가상 노션으로 발급→새 기기 등록→세션을 확인합니다. 미인증·잘못된 PIN·다른 교사 위조·외부 출처·만료·중복 사용·재발급·발급 기기 해제·PIN 변경을 검증합니다.
5. 모바일·PC 브라우저에서 PIN 확인·복사·새 기기 진입과 가로 넘침을 확인하고, 명세·부품 지도·사용 가이드·walkthrough.md를 갱신합니다. 전사 AI 검증 후 운영 배포·한국어 커밋/푸시·노션 4계층 기록까지 완료합니다.

## 완료 기준

- 교사가 관리자에게 연락하지 않고 등록된 자기 기기에서 자기 계정의 새 기기 링크를 만들 수 있습니다.
- 링크만으로는 로그인하지 못하고 기존 PIN을 확인해야 합니다. 다른 교사·학급 링크를 발급할 수 없습니다.
- 같은 계정의 기존 기기는 계속 사용할 수 있으며 등록·30일 연장이 독립적으로 동작합니다.
- 실제 사용자 PIN을 대신 입력하거나 운영 등록 링크를 Git·보고서·노션에 보관하지 않습니다.
