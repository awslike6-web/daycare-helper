# 사진 기반 행동 메모 확인·저장 계획 · 2026-10-06

사진만으로 생성한 서류에 원시 메모 근거가 남지 않는 문제를 해결한다. 사용자가 제안한 교사 확인 단계를 기존 원시 메모 저장·장기 기억 흐름에 연결한다.

1. 기존 Gemini JSON 호출·재시도·오류 분류를 공통 함수로 재사용하여 사진의 관찰 가능한 행동만 분석한다. 사진 순서로 행동 순서를 추측하거나 발화·감정·성장·교사 지원을 만들지 않는다.
2. 인증·담당반·선택 원아·관찰일·사진 동의를 검증하는 사진 메모 API를 추가한다. 분석 초안은 노션에 쓰지 않으며 사진 속 신원은 판별하지 않는다.
3. 메모 없이 사진으로 생성하면 먼저 별도 편집란의 행동 메모 초안을 보여준다. 원아·관찰일·행동 확인 후에만 기존 메모 입력창으로 반영하고 MemoStore를 통해 저장한다. 기존 메모 변경·다른 기기 충돌은 덮어쓰지 않는다.
4. 확인 전 초안은 기존 AES-GCM 기기 임시보관에 포함하고 자동 메모 저장과 분리한다. 원아·날짜·사진 변경·잠금 시 요청과 확인을 무효화하며 복원 후 다시 확인받는다.
5. 저장된 개인 메모는 기존 근거 조회·월간·분기 서류 작성에서 선택한다. 새로운 노션 DB 속성·사진 서버 보관·완료된 서식 엔진은 만들지 않는다.
6. 확인 전 저장 없음, 수정/취소/충돌/늦은 응답, 개인 원아 관계와 장기 참조, Gemini 가상 사진 요청을 검증한다. 사용 가이드·명세·부품 지도·walkthrough·당일 노션 기록을 갱신하고 기존 Worker에 배포한다.
