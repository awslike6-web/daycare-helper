# 반 전체 메모의 원아별 문장 자동 제안 계획

작성일: 2026-10-04 · 대상: 보육비서 3.6.2

## 목적

교사가 반 전체 메모를 반복해서 훑어 발췌하는 수고를 줄인다. 입력한 원문의 이름을 담당반 노션 원아 목록과 대조해 검수 가능한 후보를 즉시 제시하고 확인한 항목을 한 번에 저장한다.

## 구현 순서

1. 기존 public/js/child-links.js에 순수 문장/이름 탐색과 제안 화면을 함께 추가한다. 원문을 바꾸거나 AI에 전송하지 않고 줄바꿈·문장 경계와 이름/조사를 확인한다.
2. 실제 노션 ID로 후보를 연결한다. 성을 뺀 이름은 약칭 확인을 표시하고 동명이인은 선택을 비운다. 공동 문장은 아이별 후보에서 역할 확인을 요구하고 이름 없는 문장은 별도 목록과 수동 연결을 제공한다.
3. 원문·원아·요약·체크·저장 상태를 기존 암호화 초안에 포함한다. 메모 변경·필드 수정·복원 때 확인을 해제하고 교사/날짜/원아 변경과 잠금 시 진행 요청과 화면을 정리한다.
4. 기존 /api/logs/link-child와 원문 확보·직렬 저장을 재사용해 확인한 후보를 한 번에 저장한다. 중복 쓰기를 방지하고 실패/일부 성공을 표시하며 저장 중 수정·늦은 응답을 격리한다.
5. 명세·부품 지도·사용가이드·앱 가이드에 실제 흐름과 판단 한계를 반영한다.

## 확인 및 배포

- 이름/조사·동명이인·약칭·공동 문장·이름 없는 다음 문장·일반 단어 부분 일치·수정/복원·일부 실패·연속 탭·잠금 후 응답 회귀를 확인한다.
- 가상 교사와 가상 노션을 사용하는 실제 모바일/PC 브라우저에서 자동 제안→수정→확인→일괄 저장→개인 기록 조회 및 재진입 복원을 확인한다.
- 실제 Node 파서·800줄 상한·전체 회귀·승인된 공개 HTML AI 검사를 통과한 뒤 공식 Worker에 배포한다. 공개 리소스 반영과 기존 운영 노션 연결 검증을 확인한다.
- 한국어 커밋/푸시 후 전사 scripts/log_dev_timeline.py로 기존 당일 기록에 누적하고 4계층 연동을 재조회한다.

## 판단 경계

이름이 등장했다는 사실만으로 행동 주체를 확정하지 않는다. 원문 그대로를 제안하며 교사가 실제 원아와 역할을 확인한다. 이름 없는 문장의 주체를 앞 문장으로 추정하거나 반 공통 활동을 모든 아이에게 자동 저장하지 않는다.
