# 한 메모 집중 편집 개선 · 2026-10-18

- A: 한 번에 한 메모를 화면의 남은 공간 전체로 표시하여 세로 탐색·문맥 전환 피로를 줄인다.
- S: 기존 memo-workspace JS/CSS, 팝업 HTML, 로컬 브라우저 검사와 관련 문서만 수정한다.
- D: 기존 팝업은 PC 2열·모바일 1열 카드 목록으로 긴 목록 스크롤과 작은 고정 높이 편집란이 남았다.
- S: 기존 input 전달·저장·검수·읽기 전용·잠금/문맥 보호를 유지한다. 전체 내용을 숨기거나 잘라 저장하지 않는다. 글자를 무제한 축소하지 않으며 긴 메모는 내용창 내부에서만 스크롤한다.
- T: 한 편집란만 표시·직접 선택/이전/다음 이동·수정 보존·자동 맞춤·모바일/PC 본문 공간·긴 내용 접근·검수 해제·잠금을 실제 가상 서비스 화면에서 확인한다.

팝업 설명과 저장 상태를 짧게 접고, 편집란을 높이/너비 전체로 늘린다. 자동 맞춤은 PC 14px·모바일 16px 이상의 글자로 화면 안에 맞춘다. 직접 메모 선택과 이전/다음 버튼, 읽기 전용 표시를 제공한다. 내용이 넘치면 ‘내용창 스크롤’ 안내를 표시한다. 기존 새로고침·배포·소스 동기화·기록 절차를 따른다.
