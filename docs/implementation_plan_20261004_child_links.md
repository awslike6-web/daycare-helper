# 원아별 정확한 기록 연결 실행 계획

작성: 2026-10-04 · 대상: 보육비서 독립 저장소

## 확인한 문제

- 생성된 이름과 같은 첫 원아를 찾는 저장은 동명이인을 구분하지 못한다.
- 개별 관찰 요약에도 반 전체 원시 메모가 적재되어 다른 원아의 행동이 개인 기록에 섞인다.
- 관계가 여러 개인 이전 기록은 첫 관계만 표시하고 개인 근거 조회에 포함될 수 있다.

## 구현 순서

1. 노션 원아 ID·교사·담당반·작성일을 서버에서 검증하는 기록 연결 API를 만든다. 기존 MemoStore의 대상별 직렬 실행을 재사용한다.
2. 실제 노션에 저장한 원문에서 정확히 일치하는 발췌문만 개인 원시 메모로 저장한다. 원문 기록 ID·발췌문·검수한 요약을 함께 남기고 같은 원문·원아·발췌의 재시도는 같은 기록을 사용한다.
3. 원시 메모 단계에 원아 선택·근거 발췌·연결 버튼을 제공한다. 생성된 개별 카드도 같은 확인·저장 흐름을 사용하고 이름으로 추측 저장하지 않는다.
4. AI가 반환한 가명은 서버의 원아 ID에 대응시킨다. 확인할 수 없는 이름·가명과 동명이인은 교사가 선택하도록 표시한다.
5. 개인 근거는 정확히 한 원아의 실제 관계만 허용한다. 기존의 반 전체 메모를 넣은 개별 기록과 관계가 여러 개인 기록은 확인 필요로 표시하며 추측해서 소급 수정하지 않는다.
6. 가상 원아로 저장→원아별 조회→개인 근거 생성의 종단과 동명이인·반 격리·원문 불일치·재시도를 확인한다. 모바일/PC 화면, 전사 공개 HTML AI 검사, 운영 연구반 가상 기록 검사 후 배포·한국어 커밋/푸시·표준 노션 개발 기록을 완료한다.

## 완료 기준

- 다른 아이의 원문이 개인 기록에 통째로 복사되지 않는다.
- 동명이인은 노션 ID로 구분되며 확인되지 않은 대상은 저장할 수 없다.
- 교사가 입력한 원문·원아 연결·요약 검수 결과를 노션에서 다시 읽을 수 있다.
- 기존 원시 메모 자동 저장과 검수한 통합 서식 저장은 유지된다.
