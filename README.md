# 🧸 daycare-helper (어린이집 교사 맞춤형 AI 보육 비서)

어린이집/유치원 교사의 일상 업무를 혁신하는 2026 플래그십 AI 보육 보조 웹 서비스입니다.  
거친 단편 메모나 음성 녹음, 활동 사진(1~6장) 입력만으로 평가제 기준에 맞춘 **키즈노트 알림장, 놀이 보육일지, 평가제 관찰일지, 발달 종합평가**를 교사 스타일에 맞게 즉시 생성하고 노션(Notion)에 영구 아카이빙합니다.

- 🏰 **공식 배포 주소**: [https://daycare-helper.awslike6.workers.dev/](https://daycare-helper.awslike6.workers.dev/)
- 📦 **공식 깃 저장소**: [https://github.com/awslike6-web/daycare-helper](https://github.com/awslike6-web/daycare-helper)
- 📖 **선생님 실무 가이드**: [docs/teacher_guide.md](docs/teacher_guide.md)
- 📐 **단일 원천 상세 명세서 (SSOT)**: [docs/daycare_spec.md](docs/daycare_spec.md)

## 🚀 v3.3 핵심 기능 및 특장점

### 1. 📑 4대 서식 선택 툴바 (스마트 토글 & 70% 토큰 절감)
- **필요한 서식만 콕콕 선택**:
  - 📸 **키즈노트 알림장** (학부모용 다정체, 250~400자 생생 서술)
  - 📄 **놀이 보육일지** (평가제 및 결재용 A4 공문서 규격, HWP 표 복사 지원)
  - 🧸 **평가제 관찰일지** (월 1~2회 표준보육과정 객관체, 1차 ➔ 2차 발전 변화 연계)
  - 📊 **발달 종합평가** (표준보육 6대 영역 종합 발달 리포트)
- **4초 초고속 생성 & 70% 토큰 다이어트**: 필요한 서식만 생성하여 대기 시간 단축 및 출력 토큰 대폭 절감 (2,500토큰 ➔ 700토큰).
- **노션 데이터 무결성 백그라운드 보장**: 관찰일지 칩을 꺼두어도 AI가 `observation_summary`(1줄 핵심 관찰 요약)와 `individual_observations`를 항상 백그라운드 생성하여 노션 `DAILY_LOG_DB`에 일일 관찰 기록이 단 하루도 누락되지 않고 자동 축적됩니다.
- **영구 기억 & 가드**: 선생님의 체크 상태를 `localStorage`에 영구 기억하며, 최소 1개 이상 필수 선택 가드가 작동합니다.

### 2. 📋 원클릭 한글(HWP) 정규 표 복사 (`copyHwpTable`)
- 보육일지, 관찰일지, 발달평가 상단의 **[📋 한글(HWP) 표 복사]** 버튼 1회 터치 후 한글(HWP) 문서에 `Ctrl+V`로 붙여넣으면:
  - 어린이집 평가제 실무 규격 테이블(결재란, 관찰상황, 교사의 지원 및 평가 등)로 100% 자동 변환되어 서식 재편집 격무를 완전히 제거합니다.

### 3. 🎙️ 말로 툭툭 던지는 음성 메모 (STT) & 실시간 자동저장
- **Web Speech API 네이티브 음성 인식**: 교실에서 아이들을 보며 키워드만 말해도 단정한 문장으로 착착 기안.
- **실시간 자동저장 (Autosave)**: 타이핑 또는 음성 입력 즉시 로컬에 저장되어 브라우저 새로고침이나 화면 꺼짐에도 데이터가 100% 안전 보존됩니다.

### 4. 🗑️ 3초 2-Tap 안심 비우기 & ⏹️ AI 실시간 생성 중단
- **실수 방지 2-Tap 가드**: 휴지통 버튼 클릭 시 3초 타이머가 작동하며, 3초 이내에 1회 더 눌러야 비워지므로 소중한 메모의 우발적 삭제를 원천 방지합니다.
- **실시간 중단 (AbortController)**: AI가 문장을 작성하는 도중 언제든 **[⏹️ 생성 중단]** 버튼을 누르면 즉시 멈추고 메모를 수정할 수 있습니다.

### 5. 👥 다중 아동 자동 감지 & 우리반 기본 선택 고정
- **자동 원아 인식**: 메모 본문에 *"민서가 블록을 쌓고 하은이가 옆에서..."*처럼 여러 아이 이름이 들어가면 AI가 출현 아동을 자동 감지하여 아이별 1:1 맞춤형 알림장을 각각 분리 생성합니다.
- **우리반 기본 고정**: 원아 선택창의 기본값이 '우리반'으로 자동 설정되어 매번 아이를 수동 선택해야 하는 번거로움을 제거했습니다.

### 6. 👩‍🏫 선생님 맞춤 페르소나 & Few-shot 학습
- **선생님 문체 100% 복제**: 평소 선생님이 작성했던 알림장 예시문(1~2개)을 학습하여 선생님 고유의 문체, 호흡, 맺음말, 이모지 감성을 완벽히 재현합니다.
- **교사 스위처 3종 지원**:
  - 👩‍🍼 **공가영 선생님** (사랑반 · 만 0세 영아): 감각 탐색, 수면, 이유식 특화 다정체
  - 👩‍🏫 **공가희 주임님 ⭐** (소망반 · 만 2세 유아): 표준보육 5대 영역 연계 주임교사 정규 공문서 문체
  - 👨‍💻 **체험 · 연구반**: 신규 원아 및 서식 자유 테스트 구역

### 7. 📱 PWA 홈화면 숏컷 & 소급 캘린더
- **앱 아이콘 꾹 누르기 (롱프레스)**:
  - `🎙️ 음성 메모 바로녹음` ➔ 터치 즉시 마이크 실행
  - `📂 지난 기록 보관함` ➔ 작성해 둔 보육일지/알림장 보관함 1초 이동
- **과거 날짜 소급 캘린더**: 어제나 지난주에 작성하지 못한 일지도 날짜를 선택하여 완벽히 소급 작성 가능.

### 8. 🪄 AI 실시간 다듬기 (Quick Refine) & 안심 복원
- 원터치 칩(더 다정발랄하게, 놀이 과정 자세히, 핵심만 간결하게, 식습관/점심 칭찬 추가) 및 자유 프롬프트 직접 지시.
- **`↺ 원래대로 복원`**: 수정을 거치다가 언제든 최초 생성 초안으로 원터치 안전 롤백.

### 9. 🔒 2-Way 하이브리드 안심 보안 & 0% 전송사고
- **4자리 간편 PIN 키패드** + 30일 로그인 유지 (Remember Me).
- **원아 개인정보 마스킹**: Gemini 전송 전 실명을 `[아동A]`로 치환하고 응답 시 로컬 복원.
- **원터치 복사 및 공유**: 자동 발송으로 인한 오발송 사고를 원천 방지하는 클립보드 복사 및 네이티브 공유 (`navigator.share`).

## 🛠️ 기술 스택

- **AI Engine**: Google Gemini **`gemini-3.8-flash`** (2026 플래그십 표준)
- **Backend**: Cloudflare Workers (Edge Serverless REST API)
- **Database**: Notion REST API (`Notion-Version: 2022-06-28`)
  - `TEACHER_DB` (교사/반 관리), `CHILD_DB` (원아 마스터), `DAILY_LOG_DB` (일지 & 알림장 메인)
- **Frontend**: Modern Vanilla JS (ES2024+) + Modern CSS (Variables, Flex/Grid) + PWA Service Worker + Web Speech API (STT)

## 💻 로컬 개발 환경 실행

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 파일 생성 (.dev.vars)
cp .dev.vars.example .dev.vars
# .dev.vars 파일 내 GEMINI_API_KEY, NOTION_TOKEN 등 입력

# 3. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:8787`에 접속하여 테스트할 수 있습니다.
